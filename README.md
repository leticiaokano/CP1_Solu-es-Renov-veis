# Análise de Dados da API do ONS
> **Atividade prática com datasets de energia — Orange Data Mining, Python e Pandas**

## Sobre a atividade

Esta atividade foi desenvolvida na disciplina de **Ciência da Computação** e tem como foco a análise de diferentes conjuntos de dados relacionados ao setor de energia.

Durante a atividade, foram aplicados procedimentos trabalhados em aula para **preparar, inspecionar e analisar datasets**, utilizando ferramentas como **Python, Pandas e Orange Data Mining**.

O objetivo é relacionar cada etapa da análise ao contexto dos dados e interpretar os resultados obtidos.

## Ferramentas utilizadas

-  **Python**
-  **Pandas**
-  **Orange Data Mining**
-  **Jupyter Notebook**

## 📚 Desenvolvimento

Todos os exercícios propostos foram organizados em um único **Notebook Python (`.ipynb`)**, conforme as instruções da atividade.

O notebook contém:

- Os códigos utilizados na resolução dos exercícios;
- Os resultados obtidos durante a execução;
- As análises realizadas;
- As respostas interpretativas de cada exercício.
